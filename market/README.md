# Market Watch (alag app)

23 Nov 2026 se Market Watch Sahayak se poori tarah alag hai. Isi repo me rehta hai, par apne folder me.

- Code: `market/src/main/java` — saara market code yahin. Sahayak (`app/`) se ab kuch copy nahi hota.
- Tests: `market/src/test/java` (GitHub Actions par har push me chalte hain).
- Do app banti hain: `market-watch.apk` (Hinglish) aur `market-watch-marathi.apk` (Marathi). Link: Releases → latest.
- Data aur khel (Nifty/Bank Nifty andaza, nakli option trade): `research/` ki Python files, GitHub Actions par.

Sahayak se kya hata: Market Watch button, shares, patterns, funds, Nifty khel ki screens, aur unke alarm.
Sahayak me News Watch pehle jaisa hai (Market Watch me bhi uski apni copy hai).

Dhyan: kuch files (Planner, GeminiLive, SecureStore, Watcher wagairah) ki ab do copy hain, ek Sahayak me, ek yahan. Ek me badlav doosre me apne aap nahi jaata.
